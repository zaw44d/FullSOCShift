# Full L1 SOC Analyst Shift

With this writeup I hope to showcase both my dedication to this field and how capable I can be in reporting my findings and allowing for an ease of communication between me and any team members for an escalation or a handover. For this write up I will be doing an entire 10hr emulated shift of what I think that could encompass using the Boogeyman Series 1-3 from Tryhackme (THM), THM ItsyBitsy, THM Phishing Introduction & THM Phishing Unfolding using their SOC Simulator, THM Carnage, THM Tempest, THM IronShade. This covers different aspects from an entire compromised host, log triaging using both Elastic and Splunk, network investigation using wireshark, endpoint investigation on both windows and linux systems. These will all be completed in one shift, and each one will have it's own escalation report tied to it. It is currently 04:30 so the goal is to finish all of these before 14:30 including all the report documentation.
